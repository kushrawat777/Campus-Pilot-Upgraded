# Campus Pilot

Campus Pilot is a front-end student productivity dashboard for the FEE evaluation project.

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Included
- Dashboard
- Timetable
- To-do list with interactive completion
- Notes
- Attendance tracker + chart
- CGPA calculator
- Pomodoro timer
- College announcements
- Expense tracker + chart
- Dark mode
- Universal search
- Responsive desktop/mobile layout

The project uses HTML, CSS and JavaScript. Chart.js is loaded from a CDN for the dashboard charts.
